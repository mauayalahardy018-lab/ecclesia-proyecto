# ADR 001 Stack de Ecclesia

Estado: aceptado provisionalmente el 2026-10-30.

Decisión: Node.js LTS, Express, PostgreSQL, Zod, Vitest/Supertest, ESLint/Prettier y dependency-cruiser. Express es una opción permitida por el curso y permite aprovechar experiencia previa con JavaScript. La app anterior sin framework es referencia visual, no base de datos ni arquitectura final. Consecuencia: hay que crear estructura por módulos, migraciones y API nueva. Cambiar stack requiere otro ADR.
